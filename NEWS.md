# npANCOVA 0.2.0

##NEW FEATURES


  o Added pairwise_npANCOVA() for pairwise post hoc comparisons.
  
  o Added summary_npANCOVA() to extract the inferential results.

##CHANGES

  o Updated the package and added new functions.
	
  o The names of some functions, such as Puri_Sen_MB and Puri_Sen_MU, 
    were changed to Puri_Sen_BVCM and Puri_Sen_UVCM, respectively. 
  
  o The functions Puri_Sen_OB and Puri_Sen_OU were removed because 
    they were subsets of the functions Puri_Sen_BVCM and Puri_Sen_UVCM,
	respectively.
	

##DOCUMENTATION

  o Updated package and function documentation.

##MAINTENANCE

  o Cleaned namespace imports and resolved package check issues.
